# 比赛代码收集系统

> 一个面向编程竞赛/考试的代码提交与管理系统

## 功能概述

### 三类用户角色

| 角色 | 功能 |
|------|------|
| **超级管理员** | 管理教师账号、查看所有比赛和学生 |
| **教师** | 创建比赛、管理题目、新增学生、查看/下载学生代码 |
| **学生** | 参加比赛、上传代码、预览代码、完成提交 |

### 核心功能

- **比赛隔离**：学生只能看到自己老师创建的比赛
- **代码上传**：支持任意文件格式，多次上传自动覆盖
- **代码预览**：在线查看代码内容（语法高亮风格）
- **完成提交**：学生确认提交后锁定，不可再修改
- **下载功能**：教师可下载单题、单个学生全部代码、整场比赛所有代码（ZIP）
- **文件路径**：`uploads/{比赛代号}/{学生姓名}/{题号}/{文件名}`

## 快速启动

### 1. 安装依赖

```bash
# 后端依赖
npm install

# 前端构建（已包含编译产物，可跳过）
cd client
npm install
node -e "const {build}=require('vite');build({root:process.cwd(),build:{outDir:'dist'}})"
cd ..
```

### 2. 启动服务器

```bash
node server.js
```

服务器运行在 `http://localhost:3000`

### 3. 默认账号

| 账号 | 密码 | 角色 |
|------|------|------|
| `admin` | `admin_123`（可通过 `DEFAULT_SUPERADMIN_PASSWORD` 覆盖） | 超级管理员 |

> **第一次使用请立即修改 admin 密码！**

## 使用流程

### 教师流程
1. 使用教师账号登录
2. 进入「比赛管理」→「新建比赛」（填写名称和英文代号）
3. 进入比赛的「题目」→「添加题目」
4. 进入「学生管理」→「新增学生」（账号为身份证号/手机号/学号，最长18位）
5. 比赛结束后进入「查看提交」，预览或下载学生代码

### 学生流程
1. 使用学生账号登录
2. 进入「我的比赛」选择比赛
3. 对每道题目点击「上传代码」选择本地文件
4. 可点击「预览」查看已上传的代码
5. 全部上传完成后点击「完成提交」确认

```

├── server.js          # 主服务器入口
├── src/
│   ├── db.js          # 数据库初始化
```

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | 服务器端口 |
| `SESSION_SECRET` | 内置默认值 | Session 加密密钥（**生产环境请修改！**） |

## 生产部署建议

1. 设置环境变量 `SESSION_SECRET` 为随机字符串
2. 修改默认 admin 密码
3. 建议使用 PM2 进行进程管理：`pm2 start server.js --name code-collector`
4. 如需 HTTPS，在前面加 Nginx 反代




## 超管验收清单（手工）

### 1) 老师管理
- 进入 `超级管理员 -> 教师管理`
- 验证项：
  - 新增老师成功（账号唯一校验生效）
  - 编辑老师姓名/账号成功
  - 修改老师密码成功
  - 删除老师成功
  - 搜索（姓名/账号）可过滤列表

### 2) 学生管理
- 进入 `超级管理员 -> 学生总览`
- 验证项：
  - 顶部“所属教师”筛选有效（切换老师后列表变化）
  - 关键词搜索有效（姓名/账号）
  - 新增学生时必须选择教师；成功后显示在对应教师下
  - 编辑学生姓名/账号成功
  - 修改学生密码成功
  - 删除学生成功

### 3) 比赛总览
- 进入 `超级管理员 -> 比赛总览`
- 验证项：
  - 按老师筛选有效
  - 按关键词（比赛名/代号）搜索有效
  - 编辑比赛（名称/代号/时间/描述）成功
  - 结束比赛成功（已结束状态不可重复结束）
  - 删除比赛成功

### 4) 权限回归（防越权）
- 用教师账号登录：
  - 不能访问 `/admin/teachers`、`/admin/students`、`/admin/contests`
- 用学生账号登录：
  - 同样不能访问以上 admin 路径

### 5) 教师端回归（防功能被影响）
- 教师登录后验证：
  - `比赛管理` 可正常增删改、结束比赛
  - `学生管理` 可新增/编辑/改密/删除
  - 批量导入、批量删除仍可用
