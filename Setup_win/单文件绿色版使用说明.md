# CodeCollector 单文件绿色版使用说明

## 1. 文件说明

- 绿色版文件名：`CodeCollector-Portable-2.0.0-x64.exe`
- 该版本无需安装，适合 U 盘携带、临时部署或快速分发。

## 2. 使用步骤

1. 把 `CodeCollector-Portable-2.0.0-x64.exe` 复制到目标电脑（建议放在普通目录，不要放系统受限目录）。
2. 双击该 exe 启动。
3. 程序启动后会在系统托盘区显示图标（任务栏右下角），不再弹出空白窗口。
4. 程序会自动启动本地服务并打开浏览器：
  - `http://127.0.0.1:3000`
5. 后续可通过托盘图标管理程序：
  - 单击图标：打开系统页面
  - 右键菜单「打开管理页面」：打开系统页面
  - 右键菜单「退出」：完全退出程序
6. 首次启动如果较慢（约 5-15 秒）属于正常现象，托盘会提示当前启动状态。

## 3. 首次登录

- 默认管理员账号：`admin`
- 默认管理员密码：`admin_123`
- 建议首次登录后立即修改密码。

## 4. 数据保存位置（重点）

虽然是“单文件绿色版”，业务数据同样不会写回 exe 同目录，而是写到当前 Windows 用户目录：

- 根目录：`%APPDATA%\CodeCollector`
- 通常实际路径：
  - `C:\Users\你的用户名\AppData\Roaming\CodeCollector`

主要数据如下：

- 数据库目录：`%APPDATA%\CodeCollector\data`
  - 主库：`app.db`
  - 会话库：`sessions.db`
- 上传文件目录：`%APPDATA%\CodeCollector\uploads`

## 5. 绿色版迁移/备份

要把系统连同数据一起迁移到另一台电脑，请同时复制两部分：

1. 程序文件：`CodeCollector-Portable-2.0.0-x64.exe`
2. 数据目录：`%APPDATA%\CodeCollector`

推荐流程：

1. 旧电脑退出程序。
2. 备份 `%APPDATA%\CodeCollector`。
3. 新电脑复制绿色版 exe 到任意目录。
4. 新电脑把备份数据放到 `%APPDATA%\CodeCollector`。
5. 双击绿色版 exe 启动，确认数据已恢复。

## 6. 升级版本建议

升级绿色版时：

1. 先关闭正在运行的旧版。
2. 仅替换新的 `CodeCollector-Portable-*.exe`。
3. 不要删除 `%APPDATA%\CodeCollector`，否则会丢失业务数据。

## 7. 常见问题

- 双击 exe 没反应：
  - 先等待几秒，首次启动解压较慢。
  - 检查是否被杀毒软件拦截。
- 浏览器没自动打开：
  - 手动访问 `http://127.0.0.1:3000`。
- 程序没有主窗口：
  - 这是托盘模式的正常行为，请在任务栏右下角托盘区找到 CodeCollector 图标。
- 想彻底清除所有数据：
  - 删除 exe 文件；
  - 再手动删除 `%APPDATA%\CodeCollector`。
